# Background credits

All six wallpapers are **original procedural works** created for this
theme with ImageMagick 7.1.2 (layered gradients, geometric shapes, line
overlays, Gaussian grain, vignette, Adwaita Mono terminal type). No
photographs, no film stills, no third-party artwork, no AI-generated
imagery. All on-screen text is original wording written for this theme —
no transcribed dialogue, no studio logos, no reproduced identity artwork.

Color-story inspiration (red colony / green valley / starfield survey-grid)
comes from generic campaign-poster composition, re-executed from scratch —
no reference image was copied, traced, or embedded.
